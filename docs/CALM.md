# Calm motion

Configuration > Motion now offers Calm. It maps decorative motion to the existing no-motion rendering, keeps answer scrolling automatic only when you stay near the bottom, and preserves the browser's reading width/size choices. Device reduced-motion preference still overrides every profile.

Real pipeline status is a polite live region. Reading and action dialogs support native keyboard focus/Escape and return focus to their opening button. Ctrl+Enter or Command+Enter sends from the composer; plain Enter behavior is unchanged. Stop/retry remain available; Stop closes the client stream, not the server provider request.

Calm is an explicit readable preset, not a claim of full WCAG conformance or a screen-reader audit. No invented thinking, percentages or moving progress decorations are added. It does not change the restored original colors.
