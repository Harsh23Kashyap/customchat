# Reading preferences

The Aa control opens local reading preferences: narrow/standard/wide answer column and 15/17/19/21px text. Choices stay on this browser and do not change the app's brand settings. The dialog supports keyboard controls, Escape and focus return.

Streaming follows the latest text while you stay near the bottom. Scroll up to read earlier text and it stops moving your view; the down-arrow returns to the latest answer. Final rendering also keeps an earlier scroll position. Extremely long answers can still change height when token text is converted to paragraphs/citations; this preserves scroll offset, not an exact word anchor.

Tests include a delayed injected stream and actual browser preference/reload/mobile checks. No paid generation is required to test the controls.
